## 1. 교안 실행 화면에서 찾은 문제점과 해결

| 교안 화면에서 본 것 | 왜 문제인가 | 이번에 바꾼 방법 |
|---|---|---|
| Claude Code 모드가 Auto | 승인 없이 파일이 바뀌어 검토할 기회가 없음 | 편집 전에 묻는 모드로 바꾸고 승인 화면에서 변경 내용 확인 |
| Git·CLAUDE.md 없이 진행 | 규칙이 대화에만 남고, 단계별 되돌리기·이력 확인이 안 됨 | CLAUDE.md에 규칙 저장, 단계마다 커밋 |
| 검증·테스트 스크립트가 임시 폴더에 저장 | 다시 실행하거나 증적으로 남길 수 없음 | 프로젝트의 `tools` 폴더에 저장 |
| PDF 이름이 교안 지시와 다름 | 프롬프트의 파일 이름과 실제 파일이 달라 혼란 | 0단계에서 `gemini.pdf`, `claude.pdf`로 정확히 변경 |
| 4단계에서 25번 문제의 Next 비활성화 | "25번에서 Next로 채점"하는 기능05와 충돌 | 4단계 프롬프트에 비활성화 금지 명시 |
| 채점 알림을 닫고 Next를 또 누르면 다시 채점 | 기록이 중복 저장될 위험 | 채점은 한 번만, 채점 후 Next 비활성화 |
| 기록 리스트에 처음으로 버튼 없음 | 시작 화면으로 가려면 새로고침 필요 | 기록 화면에 [처음으로] 버튼 추가 |
| 정답 수정 지시에 없는 id(S-066) 사용 | Claude가 되묻고, 일부 문제는 교재와 불일치로 남음 | 교재 대조 문제를 표로 한 번에 확인하고 id를 정확히 지정 |
| deploy 폴더에 파일 복사 | 고칠 때마다 두 곳을 맞춰야 함 | 처음부터 `web` 폴더만 사용, 그대로 배포 |
| Netlify Drop 비로그인 업로드 | 1시간 뒤 사이트가 사라짐 | 로그인 후 업로드(또는 Claim) |
| 공유 캡처에 개인정보 노출 | GitHub 공개 시 이름·주소 노출 | 캡처의 개인정보 가리기 |

## 2. 완성한 기능

| 기능 | 내용 |
|---|---|
| 기능01 | 220문제 중 25문제를 중복 없이 무작위 출제 |
| 기능02 | 한 화면 한 문제 (객관식 라디오 버튼 / 단답형 입력칸) |
| 기능03 | 상단 바 [답 확인] [Next] [모의종료], 문제 영역 2/3 · 답 확인 영역 1/3 |
| 기능04 | 미응답 상태로 Next → "답을 하지 않으면 모의고사가 진행되지 않아요" |
| 기능05 | 25번 Next → "25문제 중 OO문제 정답", 18문제 이상 pass |
| 기능06 | 모의종료 → 날짜·회차·맞춘 개수·pass 기록 리스트 |
| 추가 | (직접 작성 — 예: 이어 풀기, 오답노트, 60분 타이머) |
