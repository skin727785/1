## 이 가이드로 하는 일

| 과제 | 이 가이드에서 |
|---|---|
| 1) 11주 시험문제 연습 웹프로젝트 Claude 코딩 성공 | A장(교안 실행 화면에서 찾은 문제점) + B장(0~8단계 개선 프롬프트) |
| 2) 반복 연습 + 중요한 VS Code 화면 캡처 → GitHub | C장(반복 방법) + 단계별 📸 + D장(캡처 방법·개인정보) |
| 3) GitHub URL 제출 | E장 |

- 만드는 앱: 220문제 중 25문제 무작위 출제, 한 화면 한 문제, 답 확인, 미응답 알림, 18문제 이상 pass, 회차별 기록 (기능 01~06)
- 걸리는 시간(대략): 1회차 90~120분(PDF 변환이 오래 걸림), 2회차 50~70분. PC와 사용량에 따라 달라질 수 있어요.
- `참고용_완성본/`은 Claude가 만든 결과가 이상할 때 **비교용**이에요. 문제 데이터는 샘플 32개라 실제 시험 공부용이 아니고, 제출할 코드는 여러분이 Claude Code로 만든 것이어야 해요.
- **문제 PDF 2개(gemini 100문제, claude 120문제)가 필요해요.** 학습사이트에 올라와 있지 않으면 강사님께 받거나, 가지고 있는 다른 문제 PDF로 하고 2단계 프롬프트의 문제 수·id 규칙만 바꾸면 돼요.

| 8 | 정답 수정 지시 "**S-066**의 정답을 ... **G-004의 ①번**으로" | 존재하지 않는 id(실제는 C-066)라서 Claude가 되물음. S-004도 교재와 맞지 않는 채로 남음 | id를 정확히 쓰는 수정 프롬프트 틀 제공, 교재 대조 목록을 3단계에서 한 번에 확인 |

| 10 | Netlify 화면: "Your project stays live for **an hour** before it expires", `Claim this site` | 로그인 없이 올리면 **1시간 뒤 사라짐** (교안의 "잠시 뒤"보다 짧음) | 로그인 후 올리거나 바로 Claim |

### 1단계 — 전체 작업 이해 + CLAUDE.md + Git 시작

```
스마트공장 수준확인 심사원 시험 대비용 모의고사 웹앱을 만들 거야.
PC와 스마트폰 브라우저에서 모두 사용할 거고, 시험이 얼마 남지 않아서 단순하고 실용적으로 만드는 게 가장 중요해.

[기술 조건]
- 순수 HTML, CSS, JavaScript만 사용 (프레임워크, 빌드 도구, 서버, DB 없음)
- 앱 파일은 web 폴더에만 둔다: web/index.html, web/style.css, web/app.js, web/questions.js
  배포할 때는 web 폴더를 그대로 올릴 거라 deploy 같은 복사본은 만들지 마
- questions.js는 window.QUESTIONS = [...] 형식으로 만들어 index.html을 더블클릭해도 동작하게
- 시험 기록은 localStorage에 저장, 화면 문구는 모두 한글

[이번 단계에서 할 일]
1. 위 4개 파일의 역할을 짧게 설명해 줘 (코드는 아직 작성하지 마)
2. CLAUDE.md를 만들어 위 기술 조건과 아래 규칙을 적어 줘
   - 요청하지 않은 기능은 추가하지 않는다 (필요하면 제안만)
   - 변환·검증·테스트 스크립트는 프로젝트 안 tools 폴더에 저장한다 (임시 폴더 금지)
   - 문제·보기 내용은 임의로 고치지 않는다. 정답 수정은 내가 id와 번호를 지정할 때만
   - 지시가 애매하거나 없는 id면 추측하지 말고 먼저 물어본다
   - 알림은 브라우저 기본 alert가 아니라 화면 가운데 알림창
   - 단계가 끝나면 "N단계: 내용" 형식으로 git commit
   - 명령 안내는 Windows PowerShell 기준
3. .gitignore에 *.pdf 를 넣어 줘 (PDF 원본은 GitHub에 올리지 않음)
4. git init 하고 "1단계: CLAUDE.md와 프로젝트 규칙"으로 커밋해 줘
그다음 내 지시를 기다려 줘.
```

**승인할 때 확인할 점**: CLAUDE.md에 "web 폴더만", "tools 폴더", "요청하지 않은 기능 금지"가 들어갔는지

### 2단계 — PDF를 문제 데이터로 변환

```
gemini.pdf와 claude.pdf를 읽어서 220문제 전체를 web/questions.js로 만들어 줘.
변환에 쓰는 스크립트는 tools 폴더에 저장해 줘.

[구성]
- gemini.pdf: 객관식 100문제, 뒤쪽 정답표 사용, 해설 없음
- claude.pdf: 객관식 100문제 + 단답형 20문제, 뒤쪽 정답·해설 사용

[데이터 형식]
객관식: { "id":"G-001", "type":"choice", "question":"문제", "options":["보기1","보기2","보기3","보기4"], "answer":2, "explanation":"" }
단답형: { "id":"S-001", "type":"short", "question":"문제", "answer":"3년", "accepted":["3년","3"], "explanation":"" }

[규칙]
- id: gemini 객관식 G-001~G-100, claude 객관식 C-001~C-100, claude 단답형 S-001~S-020
- answer는 객관식 정답 번호 1~4 (①=1)
- 줄바꿈으로 끊긴 문제 문장·보기는 자연스럽게 이어 붙이기
- 한 줄에 붙은 ①②③④ 보기는 4개로 분리
- 머리글, 페이지 번호, 영역 제목, 안내문, 응원 문구는 넣지 않기
- 문제와 보기 내용은 임의로 고치거나 요약하지 않기
- claude.pdf 해설은 explanation에 넣고, 끝의 근거 표시(규정, 공고, 표준, 일반)는 빼기
- accepted에는 같은 뜻의 답: "5명(5인)" → "5명","5인","5" / "1,000점" → "1,000점","1000점","1000"
완료 후 변환된 문제 수와 확실하지 않았던 곳을 알려 주고, "2단계: 문제 데이터 변환"으로 커밋해 줘.
```

- [ ] Claude가 220문제(객관식 200, 단답형 20)라고 보고했다

### 3단계 — 데이터 검증과 교재 대조

```

### 4단계 — 문제 화면과 기능 01~03

```
web/index.html, web/style.css, web/app.js를 만들어 줘.
[기능01] 앱을 열면 시작 화면과 [모의고사 시작] 버튼, 시작하면 220문제에서 중복 없이 25문제를 무작위로 뽑기
